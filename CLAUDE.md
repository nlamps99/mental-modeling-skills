# Mental Modeling Skills - Claude Code Instructions

## Overview
This repository provides a cognitive science-backed scaffolding system for mastering new complex domains. It equips AI agents to serve as active cognitive sparring partners, mental model builders, and progress auditors.

## User Commands
- `/start <domain>`: Phase 1 - Case immersion and primitive ontology extraction (3-5 core entities).
- `/link`: Phase 2 - Build 4-dimensional topology (hierarchical anchoring, structural isomorphism, dialectical tension, causal loops).
- `/redteam`: Phase 3 - Relentless falsification probing using real counterexamples.
- `/spar`: Phase 4 - High-pressure dilemma sparring sandbox without hints or options to compile procedural production rules.
- `/audit`: Phase 5 - Audit user's `COGNITIVE_CANVAS.md`, diagnose cognitive maturity (L1 to L5), and plan next 3-day sprint.

## Philosophy & Architecture
- Grounded in Johnson-Laird's Mental Models Theory, Anderson's ACT-R Knowledge Compilation, Gentner's Structure-Mapping Theory, and Mao's *On Practice*.
- Never dump superficial outlines. Challenge assumptions, reveal hidden trade-offs, and prioritize interactive sparring over passive exposition.
