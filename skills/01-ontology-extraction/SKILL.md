# 01 - Ontology Extraction（本体抽取与概念降维）

## 核心背景与认知原理

在面对一个全新而陌生的领域时，新手最大的障碍往往是**认知负荷过载（Cognitive Overload）**。行业黑话、次级概念、操作技巧和派生工具往往混杂在一起，让人迷失在细节中。

根据认知科学图式理论（Schema Theory），建立新图式的第一步不是搜集海量信息，而是**概念降维（Dimensionality Reduction）**——识别这个领域最底层的“不可简化本体（Primitive Entities）”与基本假设。

任何复杂学科，其基石实体通常不会超过 3~5 个（如微观经济学的“稀缺性/激励/边际成本”，认知心理学的“注意/工作记忆/图式/产生式”）。

## 何时使用

- 面对陌生复杂领域，感到信息混乱、无从下手时
- 被专业术语和行业黑话淹没，分不清主次时
- 需要为新领域画出第一张核心骨架草图时

## 工作流程

### Step 1: 具象素材沉浸（拒绝先给抽象总结）
在抽象提炼前，先让 AI 调出 3~5 个该领域最极端、最典型、最有争议的真实案例。在具体素材中形成感性认识体感。

### Step 2: 剥离黑话，过滤次级概念
剔除所有修饰性术语、应用层工具和操作套路，逼问最深层的不可拆解实体。

### Step 3: 定义实体边界与不变量
明确每一个核心实体的物理/逻辑边界：它指什么？不指什么？它的输入和输出是什么？

## 核心 Prompt 模板

```markdown
你是一位深谙第一性原理的领域认知科学家。
现在我需要从零进入并理解全新的领域：【输入目标领域，如：微观经济学 / 现代编译器 / 认知行为疗法】。

请严格执行以下三步，不要给出泛泛而谈的宏观大纲：

1. 【素材沉浸】：不要直接给理论，先给我讲 3 个该领域最经典、最具争议的真实落地案例或实验，用最直白的人话讲清楚前因后果。
2. 【本体抽取】：请暂时忽略该领域所有的实操技巧、派生工具和行业黑话。如果要用最底层的 3 到 5 个核心实体（Primitive Entities），来解释这个领域的全部运转逻辑，这几个实体分别是什么？
3. 【实体边界定义】：针对这几个实体，分别用不超过两句话给出定义：
   - 它的本质是什么？
   - 它的外延边界在哪里（它绝不是什么）？
   - 它的核心度量或状态是什么？
```

## 输出检查清单

- [ ] 是否控制在 3~5 个核心实体之内？
- [ ] 是否剔除了工具层/操作层的次级概念？
- [ ] 实体定义是否具有可操作的边界，而非空洞词条？
