# 02 - Relational Topology（知识网络与四种关联建模）

## 核心背景与认知原理

孤立的概念只是抽屉里的零件，无法产生驱动力。
- **激活扩散理论（Collins & Loftus, 1975）**：人类的长时记忆是高维语义网络，思维敏锐度取决于节点连线的导电性与拓扑结构。
- **格栅思维模型（Charlie Munger）**：单点模型会被滥用，必须将经验悬挂在多个模型交织的格栅网络（Latticework）上。
- **结构映射理论（Dedre Gentner）**：顶级顿悟来自类比推理，真正的类比不是匹配表面属性，而是匹配内部深层关系的系统结构（Relational System Alignment）。

本技能用于为抽取的实体编织四种最底层的关联连线：**层级锚定、结构同构映射、拮抗对偶、动力学回路**。

## 何时使用

- 已经识别了若干核心概念，但不知道它们如何协同工作时
- 感到知识零散、记忆容易遗忘、无法在实战中调动时
- 需要跨学科迁移经验，用已有领域的直觉吃透新领域时

## 四种连接拓扑

1. **层级锚定（Hierarchical Subsumption）**：向下找父节点。它是哪条基础科学（物理、进化论、控制论、信息论）母规律在当前场景的投射？
2. **结构同构映射（Structural Isomorphism）**：横向跨界借脑。在熟悉的领域中寻找因果拓扑完全一致的机制。
3. **拮抗对偶（Dialectical Tension）**：寻找制衡项。任何模型推向极端都是灾难，找到与之拉扯的对立面。
4. **动力学因果回路（Causal Feedback Loops）**：闭环推演。正反馈放大、负反馈制衡与时滞效应。

## 核心 Prompt 模板

```markdown
你是一位认知拓扑学与复杂系统建模专家。
基于我们已经确立的领域实体：【列出实体，如：A, B, C, D】。

请帮我构建知识与知识之间的拓扑关联网络，严格按照以下四种连接线展开推演：

1. 【层级锚定（向上溯源）】：
   - 请忽略该领域的行业表层话术，指出实体 A、B 对应的最底层上位母题分别是什么？
   - 它们是物理学、进化论、控制论、认知科学或经济学中，哪一条不可简化的底层公理在当下的具体化？

2. 【结构同构映射（跨界借脑）】：
   - 这套实体的因果交互机制，如果映射到我非常熟悉的领域【选择一项：软件工程 / 烹饪厨艺 / 健身长跑 / 军事战争 / 日常人际】：
   - 存在哪一个“深层因果关系完全一致”的同构模型？请列出一张精确的关系对照表（不要对比表面名词，只对比因果拓扑）。

3. 【拮抗对偶（张力平衡）】：
   - 如果我把【核心实体/原则 A】推向极致，系统哪个环节会最先崩溃？
   - 该领域用哪一个相反或正交的【实体/原则 B】来对它进行动态制约？高手如何在二者的张力中维持动态平衡？

4. 【动力学因果回路（闭环推演）】：
   - 在这组关系中，最容易引发恶性正反馈的回路是什么？
   - 系统的负反馈“刹车片”设置在哪里？
   - 哪两个变量之间存在显著的“时滞效应（Delay）”，容易诱导人产生误判？
```

## 输出检查清单

- [ ] 是否为新概念找到了可依赖的上位常识主干？
- [ ] 跨界映射是否做到了“深层因果关系一致”，而非表面形式附会？
- [ ] 是否为核心原则指出了边界与拮抗平衡项？
- [ ] 是否画出了包含正负反馈的闭环动态？
