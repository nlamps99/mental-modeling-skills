# 04 - Procedural Sparring（程序性编译与两难交互沙盒）

## 核心背景与认知原理

- **ACT-R 认知架构与知识编译（John Anderson）**：
  - **陈述性知识（Declarative Knowledge）**：“知道是什么”（What）。存在于工作记忆，容易遗忘，无法直接变现为战斗力。
  - **程序性知识（Procedural Knowledge）**：“知道怎么做”（How）。以“产生式（Production Rules: IF [状态] THEN [动作]）”存在于直觉。
  - **知识编译（Knowledge Compilation）**：将陈述性概念转化为程序性直觉的唯一途径，是在密集的情境决策中不断“受挫-调用-纠偏”。
- **认知学徒制（Collins, Brown, Newman, 1989）**：通过“建模（Modeling）-指导（Coaching）-脚手架（Scaffolding）-褪除（Fading）”，让思考过程外显化并转化为熟练本能。

本技能将 AI 部署为一个**严厉、实时交互的两难考官**。AI 绝不给出标准答案，而是抛出充满灰度的实战情境，迫使学习者调动多个冲突模型做出生死抉择。

## 何时使用

- 理论都看懂了，但一到实战不知道如何动手时
- 需要在多个相互冲突的原则之间进行高难度权衡训练时
- 想要摆脱对 AI 的依赖，独立建立决断直觉时

## 对抗工作流规则

1. **单次一题，绝不剧透**：AI 一次只抛出一个真实情境，不给选项，不给参考答案。
2. **强制逼问代价**：无论用户做出何种选择，AI 必须立刻指出该选择带来的“次生灾难与代偿代价”。
3. **逐级加压**：每一道题都比上一道题更加极端，直到逼出用户的底层决策原则。

## 核心 Prompt 模板

```markdown
你是一位极其严苛的实战考核导师。
我目前正在训练【某某领域】的实战决断能力。我需要练习协调的核心模型包括：【列出 2~3 个模型，如：专注模型 vs 探索模型，短期效率 vs 系统冗余】。

请立刻开启“程序性对抗沙盒（Procedural Sparring Sandbox）”，严格遵守以下对练规则：

1. 【场景生成】：请立即给我抛出一个发生在该领域真实一线的极端两难情境。该情境必须具备：
   - 强烈的现实灰度，没有任何皆大欢喜的标准答案；
   - 模型 A 的诉求与模型 B 的底线在此发生不可调和的剧烈冲突；
   - 存在紧迫的时间与资源硬约束。
2. 【禁止剧透】：请不要给出任何选项（A/B/C/D），不要给出任何分析提示，直接把问题抛给我，问我：“面对这个局面，你第一步怎么做？你决定牺牲哪一部分？”
3. 【等待我作答】：等我回复我的决断推演后，请无情指出我的逻辑盲区，说明我的决策将引发哪种致命的次生灾害，然后再出下一题。

现在，请出第 1 题：
```

## 输出检查清单

- [ ] 题目是否杜绝了“伟光正”的两全方案？
- [ ] 是否强迫用户直面“牺牲与代偿”？
- [ ] 是否在用户回答后完成了批判性反馈（指出盲区与代价）？
