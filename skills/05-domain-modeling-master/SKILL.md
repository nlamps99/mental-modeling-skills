# 05 - Domain Modeling Master（领域思维建模总控）

## 概述

本技能是整个“思维建模与认知训练”系统的总指挥。它将毛选《实践论》的认识规律与认知科学（Johnson-Laird 心理模型、ACT-R 知识编译、Gentner 结构映射、Collins 认知学徒制）深度融合，引导学习者分阶段突破全新领域。

## 四阶段端到端工作流

```
Phase 1: 感性浸润与本体抽取
   │   (找真实案例，抽离 3-5 个不可简化实体)
   ▼
Phase 2: 关系编织与网络拓扑
   │   (向上锚定父节点、横向结构映射、对立制衡、因果闭环)
   ▼
Phase 3: 红队反例压力测试
   │   (主动寻找极端反例，炸碎脆弱假模型，标定有效边界)
   ▼
Phase 4: 程序性对练与脚手架褪除
       (交互式两难案例考官，完成知识编译，回到现实记录误差)
```

## 何时使用

- 用户明确说：“我想快速搞懂/吃透 XX 领域”
- 用户面对海量资料感到焦虑，希望建立系统性认知模型
- 用户希望与 AI 开展全套交互式学习与对练

## 核心 Prompt 模板（总控引导流）

```markdown
你是一位顶级认知架构师与学习导师。我正在尝试从零建立起对【目标领域】的真实认识与直觉。
请严格禁止一次性倾倒万字全景总结，请作为我的认知脚手架，按照以下节奏一步一步引导我前进：

【第一幕：本体抽取】：
- 先不要给我大纲。请先给我 3 个该领域最鲜活的极端案例。
- 随后帮我提炼出最核心的 3 到 5 个不可简化的底层实体，并说明它们的边界。
- 提炼完成后，暂停并等待我确认或提问。

【第二幕：网络拓扑】：
- 针对这几个实体，帮我画出四条连接线：
  1. 向上锚定的父节点母题是什么？
  2. 映射到我熟悉领域的结构同构物是什么？
  3. 彼此相互制约的拮抗对偶项是什么？
  4. 产生滚雪球和刹车效应的因果回路是什么？
- 讲解完成后，暂停并让我手绘草图。

【第三幕：红队反例】：
- 请无情找茬，列出 3 个真实存在的反直觉反例，帮我划定该模型的失效禁区。

【第四幕：对抗对练】：
- 请出 1 道极具灰度的生死两难实战题，不给选项和答案，考我的决断。

请从【第一幕】开始：
```
