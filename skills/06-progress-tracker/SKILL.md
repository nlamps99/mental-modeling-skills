# 06 - Progress Tracker（认知进度跟踪与画布审计）

## 核心背景与认知原理

在漫长的新领域探索中，绝大多数人半途而废的原因是**认知盲目感（Cognitive Blindness）**：不知道自己现在处于什么水平，不知道当下的卡点是在实体层、关系层还是实战层，更不知道下一步该练什么。

本技能通过审计用户的《领域认知画布（Cognitive Canvas）》，结合 Dreyfus 技能习得模型（Novice to Expert）与 ACT-R 编译状态，给出精准的认知层级诊断与针对性冲刺动作。

## 何时使用

- 学了一个新领域几天后，感到瓶颈、想要复盘当前认知成熟度时
- 维护和更新个人的《领域认知画布（COGNITIVE_CANVAS.md）》时
- 想让 AI 作为导师，检查自己的认知盲区并规划下一阶段训练时

## 核心 Prompt 模板

```markdown
你是一位顶级认知架构评估导师。
这是我针对【目标领域】正在维护的《领域认知画布》（附在下方）：
--------------------------------
【在此粘贴你的 COGNITIVE_CANVAS.md 内容】
--------------------------------

请帮我执行严格的“认知模型成熟度审计”，按照以下格式输出诊断：

1. 【认知层级诊断】：
   - 评估我当前处于哪个认知层级（L1 迷雾期 / L2 实体期 / L3 网络期 / L4 检验期 / L5 编译期）？
   - 给出判定依据（有哪些证据表明我达到了该层级？距离下一层级的差距是什么？）。

2. 【画布薄弱点红牌警告】：
   - 审查我的实体清单：是否存在把次级工具误当核心本体的情况？
   - 审查我的知识网络：四条连接线中哪一条最薄弱、最空洞？
   - 审查我的反例与产生式：是否有逃避灰度、两全其美的自欺欺人现象？

3. 【下一阶段冲刺清单（Next Sprint）】：
   - 为我量身定制未来 3 天的最小针对性动作（具体到：向 AI 索取哪个方向的反例，或者开展哪种主题的两难对练）。
```

## 输出检查清单

- [ ] 是否准确指出了认知画布中的具体空缺与薄弱项？
- [ ] 是否根据当前层级给出了可落地的下一步训练动作，而非宽泛口号？
